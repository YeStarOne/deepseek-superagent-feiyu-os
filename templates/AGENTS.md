# AGENTS.md（模板）

> 复制到一个新项目根目录，把 `<>` 换掉。这个文件是给"进来的会话"看的，不是给人看的宣传。

## 项目
<一句话：这是什么、给谁用、现在到哪一步>

## 成员与权限
| 席位 | 能改什么 | 不能改什么 |
| --- | --- | --- |
| 总架构 | `<main>`、决策、计划 | 业务代码 |
| <席位> | `<路径>` | `<路径>` |

## 三条边界
1. 开发期只改仓库与配置；运行时只消费配置。
2. 共享资源动前发 LOCK，结束 UNLOCK。
3. 合并权唯一：`<谁>`。

## 红线
- 密钥只写环境变量名，值永不入仓。
- 真实身份、地址、对话、数据不进仓。
- 没有证据不说"已完成"。

## 命令
```bash
<安装>   <启动>   <体检>   <测试>
```

## 交接
每轮结束写 `HANDOFF.md`：现状 / 已做（证据） / 未做 / 验收命令。
